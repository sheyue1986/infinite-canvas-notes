# Infinite Canvas Notes · 无限画布

面向建筑、景观和城市设计的本地优先画布工作台。可在同一个项目中校准场地底图、标注实地尺寸、从三维模型取景、叠画手绘方案，再把画框组织成汇报幻灯片。也可用于视觉笔记、关系图、界面原型和素材复用。

[打开网页版](https://sheyue1986.github.io/infinite-canvas-notes/) · [下载 Windows x64 便携版](https://github.com/sheyue1986/infinite-canvas-notes/releases/tag/v0.2.1-r10) · [本地部署](#从仓库运行) · [备份与迁移](#备份与迁移)

## 运行方式

| 方式 | 适合场景 | 环境 |
| --- | --- | --- |
| GitHub Pages | 即开即用的画布、地图、演示和通用三维格式取景 | 支持 IndexedDB 的现代浏览器，访问站点需要联网 |
| Windows x64 便携版 | 本机绘制、离线演示和原生模型转换 | 推荐 Windows 11 x64，需 Microsoft Edge WebView2 x64 运行时 |
| 从仓库运行 | 本地部署、开发和自建静态站点 | Node.js 22.12 或更新版本 |

在线地图和三维预览需要 WebGL 2。Windows 便携版可离线打开已有项目、绘制、播放本地媒体并导出演示。在线地图、在线地名查询和远程模型服务需要网络。

### Windows x64 便携版

1. 从 [0.2.1 r10 发布页](https://github.com/sheyue1986/infinite-canvas-notes/releases/tag/v0.2.1-r10) 下载 `Infinite-Canvas-Notes-0.2.1-r10-Windows-x64.zip`。发布页同时提供 SHA-256 校验文件。
2. 完整解压到固定目录。将 `site/`、`runtime/` 和解压后的其他文件与 `Infinite Canvas Notes Desktop.exe` 保存在一起。
3. 若系统缺少 WebView2，请安装 [Microsoft Edge WebView2 Evergreen x64](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)。退出正在运行的旧版，再双击桌面程序。启动器使用回环地址 `http://127.0.0.1:4173/`。
4. 如需固定到任务栏，在 Windows 中右键 EXE 或其快捷方式，选择「固定到任务栏」。

便携包已包含应用运行时。日常绘制和演示无需安装 Node.js 或 .NET SDK。升级前可通过应用内备份保存项目和素材。

### 从仓库运行

```sh
git clone https://github.com/sheyue1986/infinite-canvas-notes.git
cd infinite-canvas-notes
npm ci
npm run build
npm start
```

打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)，保持启动窗口运行。也可以从仓库的 **Code → Download ZIP** 下载、解压后执行最后三条命令。Windows 完成安装依赖和构建后，可双击 `启动无限画布.bat`。

## 绘制、形体与媒体

- **工具轮**。八个槽位可右键替换。切换工具和通过快捷键激活时保留上次的参数，再次点击当前工具打开设置。工具轮下方可展开放大镜和套索，也可切换为横向工具栏。
- **笔刷**。钢笔、墨水笔、压感笔、固定宽度笔、软硬铅笔、马克笔、纹理印章和水彩。可即时试画，调整笔宽、不透明度、平滑度、线型、虚线密度，以及压力、速度和响应曲线。纹理印章和水彩还可调间距、散布、旋转和着色量，纹理印章支持导入笔尖。笔刷预设可通过 `.brush.json` 迁移。
- **颜色与填充**。圆盘的大圆控制线色，小圆控制填充色。支持 COPIC 色环、HSL、RGB、色值输入、画布吸色和自定义色板。闭合轮廓应用当前填充，默认透明，填充不透明度可单独设置。油漆桶可填充多条线围成的区域，并支持容差调整。
- **基础形体**。矩形、椭圆、菱形、三角形、多边形、漫画对话气泡和云形。多边形可设 3–32 边。绘制成形可将常见手绘轮廓规整为可编辑图形。右键选择「更换形状」后点选图标即可转换，已有的文字和箭头绑定随对象保留。
- **便签与文本**。便签使用可编辑绑定文字，可右键加入工具轮，放置后按 Enter 编辑。尺寸标注和手写 OCR 结果使用 Excalidraw 手绘字体。
- **图片、GIF 和视频**。使用同一个图片工具导入本地文件。GIF 在画布上播放，视频可点击画布内的播放按钮。视频能否播放取决于系统解码能力，常用格式为 MP4（H.264）和 WebM。图片上限 25 MB，视频上限 100 MB。另支持嵌入网页、图片局部擦除和魔棒。

## 选区、图层和精准绘图

选中单个对象、多个对象或群组后，浮动工具条提供关联、复制、分组、锁定、删除、水平及垂直镜像。对齐菜单含四边对齐、水平及垂直居中、水平及垂直分布，分布用于至少三个独立对象或组。支持的选区可通过角点进行缩放、拉伸、旋转和扭曲。

| 工作内容 | 功能 |
| --- | --- |
| 图层组织 | 自动或手动组织、调整顺序、隐藏、锁定、透明度、专注、复制和合并 |
| 网格和吸附 | 点阵、方格、横线、等距和三角网格，一至三点透视，可调间距、密度和方向 |
| 比例和标注 | 两点校准、常用比例、实地单位、长度标注和绘制过程读数 |
| 辅助线和识别 | 直线、圆弧、角度、椭圆和矩形辅助线，控制点和停笔规整 |
| 标注样式 | 可设主线和引线的线型、宽度、颜色、透明度及标注字号。两侧斜短线比主线和引线中较粗的一条再粗 3 pt |
| 快捷键 | 主菜单「快捷键设置」可分别编辑功能命令、工具与笔刷。支持导入和导出快捷键 JSON，支持为打开更换形状面板及直接转换指定形状设置按键 |

默认 `P` 为钢笔，`T` 为文字，`E` 为对象橡皮，`Z` 为放大镜，`B` 为填充，`9` 打开媒体导入。`Alt+1` 至 `Alt+8` 切换工具槽，`Alt+L` 切换实线与虚线。已有的用户自定义命令优先于工具默认键。

## 场地底图与三维取景

在项目画廊选择「＋ 地图项目」可搜索地名、地址或输入经纬度，拖动和缩放街道图后将取景保存为锁定底图。也可导入 PNG、JPG 或 WebP 正射影像及测绘底图，单张上限 32 MB，输入整张图覆盖的实地宽度以建立比例。底图入项目后可离线描绘。

在「图层 → 精准 → 测量」中可切换 mm、cm、m、km、in、ft，设置小数位和两点校准比例。在线底图尺度由取景中心纬度换算，设计控制尺寸应根据实测数据或校准影像复核。在线街道图使用 OpenFreeMap、OpenMapTiles 与 OpenStreetMap 数据，地名查询使用 Photon。 [底图服务](https://openfreemap.org/) · [OpenStreetMap 数据说明](https://www.openstreetmap.org/copyright) · [Photon](https://github.com/komoot/photon)

左上角「导入三维模型」支持透视和正交取景、模型分组显隐、剖切、日照及投影阴影。可将多个独立视角保存为项目草图，并导出底图加草图 PNG 或透明草图 PNG。一次导入一个主模型及配套文件，总计上限 256 MB。

| 格式 | 读取方式 |
| --- | --- |
| Rhino `.3dm`、`.glb`、`.gltf`、`.obj` | 浏览器内读取，外部缓冲、MTL 和贴图可随主文件一起选择 |
| SketchUp `.skp` | Windows 便携版通过本机 SketchUp 2023 读取组件处理，也可先导出 OBJ |
| Blender `.blend` | Windows 便携包带 Blender 5.0 转换环境。使用外链资源的模型可先打包外链或导出 GLB |

## 工作侧栏、图表和 AI

右上角展开工作侧栏，可在查找内容、素材库、AI 生成、图表编辑器和演示文稿之间切换，用图钉固定侧栏。

- **内容和素材**。搜索画布文字。素材库支持搜索、收藏、拖放、批量处理、文件夹和嵌套素材包，可导入图片或将选区保存为素材。
- **表格与图表**。可从网页、Excel 或剪贴板粘贴表格，识别 HTML 表格、TSV、CSV 和可识别的 Markdown 表格。表格和数据图表支持预览，并以可编辑对象插入。Mermaid 支持在应用内预览和插入。
- **文字或图片生成图解**。输入描述，或选用参考图片，生成可预览的 Mermaid 流程图、序列图或类图，再插入当前画布。
- **线框转交互原型**。可框选既有线框，或插入桌面、平板、手机画框与线框模板。选中多个画框后，模型结合布局、截图、箭头和画布说明生成多页可点击原型，可在应用内演示，并复制或下载 HTML。
- **手写 OCR**。选择手写笔迹、图片或画框，在「AI 生成 → 手写转文字」识别，校对后将结果以手绘字体插入为可编辑文本。

在「模型与 API Key」可选 DeepSeek 或兼容 Chat Completions 的服务。DeepSeek 预设使用官方 `deepseek-flash`，当前对应 DeepSeek-V4.1-Flash-1017，支持文字与图像。选择「MCP 工具」可连接支持 Streamable HTTP 的服务器，并勾选允许模型使用的工具。远程接口需允许应用来源的跨域请求。密钥和 MCP 令牌仅在当前运行期间使用。点击生成或识别时，相关描述、图像或选区会发送给所选模型服务。 [DeepSeek 版本说明](https://api-docs.deepseek.com/updates/) · [MCP Streamable HTTP](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http)

## 本地演示文稿

侧栏「演示文稿」将画布中的画框列为幻灯片，可新建画框、框选内容、预览缩略图并调整顺序。每页可添加演讲者备注，也可设置选中的对象在后续步骤出现。

演示时可全屏、用键盘翻页、开关激光笔，或查看当前备注与下一页预览。画布中的 GIF 和视频可以在本地演示中播放。支持导出 PDF、PPTX 和可离线翻页的 HTML。文件以画面快照保存，PPTX 另保留演讲者备注。演示功能无需 Excalidraw+ 订阅，手机扫码遥控、在线语音和云端分享尚未接入。 [Excalidraw 演示参考](https://plus.excalidraw.com/use-cases/presentations)

## 备份与迁移

画布、项目和素材存放于当前浏览器或桌面 WebView2 的本地存储。网页版、`localhost`、`127.0.0.1`、不同端口和不同配置文件分别保存数据。

| 内容 | 导出 | 导入 |
| --- | --- | --- |
| 项目、底图、比例、图层、三维视角和演示设置 | 左上角菜单 →「导出项目备份」，保存 `.canvas.json` | 画廊 →「导入项目」 |
| 整个素材库或单个素材包 | 素材库菜单 →「导出素材库」或「导出素材包」 | 素材库 →「导入素材库或素材包」 |
| 快捷键 | 快捷键设置 →「导出快捷键」 | 快捷键设置 →「导入快捷键」 |
| 笔刷及色板 | 笔刷或颜色菜单的导出项 | 笔刷库或颜色菜单的导入项 |
| 通用画布 | 左上角菜单 →「导出 Excalidraw 文件」 | 画廊或兼容的 Excalidraw 工具 |

项目画廊支持新建、打开、重命名、复制和删除。完整迁移时优先使用项目备份。应用专有的形体轮廓、媒体播放和演示设置在其他 Excalidraw 编辑器中的显示取决于其兼容能力。清理站点数据、换电脑或更换运行方式前，先导出需要迁移的内容。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| `ERR_CONNECTION_REFUSED` 或 4173 端口被占用 | 退出旧版服务后启动桌面程序，或重新运行 `npm start` |
| Windows 启动器找不到应用文件 | 完整解压 ZIP，检查 EXE 旁边是否有 `site/index.html`，并确认已安装 WebView2 |
| 换电脑或浏览器后找不到画布 | 用原环境导出项目及素材备份，再到新环境导入 |
| AI 或 OCR 无法连接 | 检查网络、API Key、模型权限及接口的跨域设置，OCR 需要支持图像输入的模型 |
| 底图无法加载 | 检查 WebGL 2 和网络，也可改用已知实地宽度的本地影像 |
| 视频无法解码 | 可转换为 MP4（H.264）或 WebM 后导入 |

## 项目结构与部署

- `published-site/` 是本机桌面版对应的已构建站点，GitHub Pages 和 Windows 便携包使用同一发布入口。`npm run build` 将它复制到 `dist/`，资源路径兼容站点子目录。
- `src/` 包含 React/Vite 开发入口和可编辑代码，包含多个与发布站点共用的功能模块。`npm run dev` 启动开发环境，`npm run build:source` 构建开发入口。
- `windows-launcher/` 保留旧版启动器源码。当前便携包使用 Windows 桌面启动器和 WebView2，包含回环服务和本机模型转换入口。
- 画布基于 Excalidraw，三维取景使用 Three.js 和 Rhino3dm，底图使用 MapLibre GL JS。演示导出使用 pdf-lib 和 PptxGenJS。

修改演示导出依赖或导出实现后，可运行 `node scripts/build-presentation-export.mjs` 重新生成发布站点的导出模块。
