# Infinite Canvas Notes · 无限画布

基于 Excalidraw 的本地概念设计画布，适合建筑与景观草图、视觉笔记、分镜和素材整理。项目可以包含主画布和多张三维视角草图。笔刷、图层、精准工具和素材库按需展开。

## 在线使用与 Windows 本机版

- [打开 GitHub Pages 网页版](https://sheyue1986.github.io/infinite-canvas-notes/)。网页支持二维画布、三维取景和草图，可导入 Rhino 3DM、GLB、glTF、OBJ。
- Windows x64 版可从 [GitHub Actions 构建记录](https://github.com/sheyue1986/infinite-canvas-notes/actions/workflows/deploy-pages.yml) 的成功运行中下载 `Infinite-Canvas-Notes-Windows-x64`。解压到同一个目录，双击 `Infinite Canvas Notes.exe`。本机版通过已安装的 SketchUp 2023 读取 SKP，通过已安装的 Blender 转换 BLEND。模型软件和读取组件由各自的安装程序提供。
- 项目数据留在当前浏览器。网页与 Windows 本机版之间可用「导出项目备份」迁移，三维项目备份包含模型、取景设置和各视角草图。

## 在另一台电脑运行

适用 Windows、macOS 和 Linux。安装 [Node.js](https://nodejs.org/) 22.12 或更新版本。首次安装依赖需要联网，之后可离线启动和绘图。

```sh
git clone https://github.com/sheyue1986/infinite-canvas-notes.git
cd infinite-canvas-notes
npm ci
npm run build
npm start
```

也可从 GitHub 的 **Code → Download ZIP** 下载，解压后在包含 `package.json` 的目录执行最后三条命令。

打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/) 并保持终端开启。Windows 完成安装和构建后，可双击 `启动无限画布.bat` 启动。若 4173 端口已占用，先关闭旧版启动窗口，再启动新版。

更新代码后重新运行 `npm ci` 和 `npm run build`。开发时可运行 `npm run dev`。构建产物在 `dist/`，包含静态部署所需文件。通过 HTTP 访问构建产物。

## 功能与入口

| 功能 | 使用方式 |
| --- | --- |
| 项目画廊 | 新建、打开、重命名、复制、删除项目。可导入项目备份或 `.excalidraw` 文件。 |
| 圆盘工具 | 右键点击槽位，从「基础笔刷」「工具」或「我的笔刷」选择。圆盘中心显示当前工具属性。使用选择工具选中已有对象，可编辑该对象支持的属性，例如笔迹线型、颜色和文字字号。 |
| 笔刷与快捷键 | 钢笔、压感笔、铅笔、马克笔、纹理印章、水彩及自定义预设。支持压感设备输入、笔宽、平滑度、不透明度、实线与虚线及虚线密度。左上角「快捷键设置」可为工具、自定义笔刷、吸附、网格等精准操作改键。默认 `P` 钢笔、`T` 文字、`E` 对象橡皮。 |
| 颜色与色板 | 点击圆盘中心色点打开 Copic、HSL 或 RGB 色轮。可从画布取色、选择 Copic 色系、创建和导入导出色板，并将常用色板固定到圆盘。 |
| 油漆桶 | 将「填充」分配到槽位，或用默认快捷键 `B` 启用。圆盘中心可调 0–255 容差，默认 32。支持闭合矢量区域，生成色块可编辑、删除、撤销和重做。 |
| 图层与精准工具 | 从左上角打开图层，可排序、隐藏、锁定、调整不透明度、进入专注模式。图层面板内展开「精准」，可设置网格与透视、吸附、辅助线、停笔识别、两点比例校准和长度标注。 |
| 素材库 | 从右上角打开。导入图片或把画布选区保存为可复用素材，支持搜索、收藏、批量操作、拖放和素材包嵌套。素材包可移动到根目录或另一个素材包。 |
| 放大镜与套索 | 圆盘下方的工具按钮可展开或收起放大镜与套索。按 `Z` 启用放大镜，按住左键上下拖动缩放。 |
| 三维草图 | 从主菜单导入模型，调整取景、日照、阴影、分组和剖切，再保存视角并绘图。底部视角条可切换、重命名、复制、排序或删除。 |
| 对象关系 | 选中对象后可通过画布右上角的链接入口创建、查看和定位关系。 |

## 换电脑、换浏览器和备份

项目和素材保存在当前浏览器的本地存储中。请在原电脑先导出两类文件，再到新电脑分别导入。

| 内容 | 原电脑导出 | 新电脑导入 |
| --- | --- | --- |
| 项目和项目设置 | 打开每个项目，选择左上角菜单 →「导出项目备份」，保存 `.canvas.json` | 项目画廊 →「导入项目」 |
| 素材与素材包 | 素材库「⋯」→「导出素材库」，或从单个素材包菜单导出 | 素材库「⋯」→「导入素材库或素材包」 |
| 通用画布文件 | 左上角菜单 →「导出 Excalidraw 文件」 | 项目画廊或其他兼容 Excalidraw 的工具 |

跨电脑迁移优先使用项目备份，可保留项目中的图层、精准设置、对象关系和图片。自定义笔刷、色板可在各自的面板单独导出。个人素材通过导入迁移，仓库提供空白素材库。

在同一台电脑升级时，继续使用同一个浏览器配置文件和地址 `http://127.0.0.1:4173/`。浏览器会把 `localhost`、不同端口和 GitHub Pages 当作不同的存储位置。首次从旧版迁移时，旧的自动保存画布可能以「原有画布」出现在画廊。

## 技术说明

- Excalidraw 0.18.1、React 和 Vite。依赖由 `package-lock.json` 锁定。
- 项目和素材使用浏览器本地存储。素材索引、缩略图和原始数据按需读取。
- 水彩与印章以图像对象保存，常规笔迹和几何对象可继续编辑。精准工具适用于概念设计尺度。
- GitHub Pages 工作流从 `main` 安装依赖并构建同一份源码。
